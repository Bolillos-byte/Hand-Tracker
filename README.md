# Hand-Tracker
Proyecto de seguimiento de manos utilizando OpenCV y MediaPipe
Proyecto de seguimiento de manos utilizando **OpenCV** y **MediaPipe**. Este script detecta manos en tiempo real desde la cámara, dibuja puntos de referencia, calcula la distancia entre el pulgar e índice, y muestra la información en pantalla.

---

##  Tecnologías utilizadas

- [Python](https://www.python.org/)
- [OpenCV](https://opencv.org/)
- [MediaPipe](https://mediapipe.dev/)
- [NumPy](https://numpy.org/)

---

Funcionalidades
- Detección de manos en tiempo real.
- Dibujo de puntos de referencia en cada mano.
- Cálculo de distancia entre el pulgar e índice.
- Visualización en una región de interés (ROI) personalizada.
- Superposición de gráficos en el video en vivo.
